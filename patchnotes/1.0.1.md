# Hallowed 1.0.1

**Supported platforms:** Minecraft 26.3 and 26.2 (Fabric, NeoForge) · 1.21.1 (Fabric, NeoForge) · 1.20.1 (Fabric, Forge) · Java 25 / 21 / 17 · Fabric API on Fabric

## Fixed

- **Dispensers hatch Hallowed spawn eggs.** On Minecraft 1.21.1 (Fabric and NeoForge) and 1.20.1 Fabric, a
  dispenser spat the Spirit, Will-o'-the-Wisp and Hollow Horseman spawn eggs out as items. It now spawns the mob in
  front of it, like any vanilla spawn egg. Nothing changes on 1.20.1 Forge, 26.2 or 26.3.
- On 1.21.1, picking a Spirit or the Hollow Horseman with the middle mouse button in creative mode now gives you its
  spawn egg.

No config or save changes.
